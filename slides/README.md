# Slides

One composed Marp deck for the Personal Agentic AI workshop. Source lives in `src/`; build output goes to `dist/`.

## Layout

```text
src/        # one fragment per phase, composed in filename order
themes/     # workshop.css, the single source of truth for look
assets/
  diagrams/     # copies of ../../diagrams, renumbered by order of appearance
  screenshots/  # captured UI steps, tracked in MANIFEST.md
dist/       # build output (gitignored, self-contained)
  deck.md       # composed deck, regenerated by build.sh
  deck.html     # primary artifact
  deck.pdf      # backup and handout
  assets/       # copied from ../assets so the folder is shareable
```

## Build

```bash
./build.sh              # HTML, then PDF if a browser is available
./build.sh --html-only  # HTML only
./build.sh --pdf        # HTML + PDF, PDF failure is fatal
./build.sh --docker-pdf # HTML locally, PDF via the marp-cli container
```

Output: `dist/deck.html` and `dist/deck.pdf`. `dist/` is self-contained: the HTML references `dist/assets/`, so the whole folder can be shared or zipped as-is.

HTML needs no browser. PDF uses Chrome, Edge, Firefox, or (on macOS) Helium when installed at `/Applications/Helium.app`. Override browser selection with `MARP_BROWSER_PATH=/path/to/browser ./build.sh --pdf`. Otherwise, use `--docker-pdf` to render in the `marpteam/marp-cli` container.

## Preview

```bash
marp -s .          # serve this directory, open in a browser
marp -w src        # watch mode for a fragment
```

To preview the composed deck while editing, run `./build.sh --html-only` and open `dist/deck.html`.

## Adding or editing content

- Add a phase file to `src/` named `NN-name.md`; it is composed in filename order.
- Only `src/00-title.md` carries the Marp frontmatter. Every later fragment starts with a `---` slide separator.
- Presenter notes are HTML comments at the end of a slide.

## Slide archetypes

Apply with a per-slide directive, for example `<!-- _class: demo -->`.

| Class | Use |
|---|---|
| `title` | Deck title |
| `section` | Phase divider |
| `concept` | Diagram slide, `![bg right:52% contain](...)` |
| `demo` | Screenshot plus numbered steps, `![shot right:46%](...)` |
| `checkpoint` | "You should now have" |
| `pitfall` | Watch out, amber |
| `lab` | Do-it-now, teal |
| `wrap` | Recap |

## Distributing

- **HTML** is the primary artifact: self-contained (in `dist/`), offline, presenter mode built in.
- **PDF** is the backup and handout, with notes and outlines.
- Build output is gitignored. Rebuild from source, or attach artifacts to a release.

Pin the Marp version when distributing so rendering stays consistent. Verified with `@marp-team/marp-cli` v4.4.0.
