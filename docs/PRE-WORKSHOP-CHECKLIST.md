# Pre-Workshop Checklist

Complete this before workshop day.

- [ ] Container runtime installed
- [ ] `docker version` works
- [ ] `docker compose version` works
- [ ] Tailscale account created
- [ ] Workshop computer joined to your tailnet
- [ ] Second Tailscale device added (recommended)
- [ ] OpenRouter account created
- [ ] $5 OpenRouter credit purchased
- [ ] `agentic-ai-workshop` API key created
- [ ] API key limit set to $5
- [ ] API key saved securely

**Never send your API key to the instructor or put it in GitHub.** You will enter it directly into Bifrost during the workshop.

If your key is accidentally exposed, revoke it in OpenRouter and create a replacement.
